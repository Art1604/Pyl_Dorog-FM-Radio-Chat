Эта папка предназначена для хранения собственных GIF-анимаций радиостанции «ПыЛь_ДоРоГ FM», используемых в чате на нашем сайте.

Формат файлов: .gif

Анимации загружаются локально с GitHub Pages.

Каждой GIF присваивается уникальный код (например, pylgif:001), который автоматически преобразуется в анимированное изображение на сайте радиостанции.

На оригинальном Волнорезе код отображается как обычный текст.
